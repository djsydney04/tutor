# Ponytail source

The six Ponytail skills in this shared repository are imported from Dietrich Gebert’s MIT-licensed
[Ponytail v5.3.3](https://github.com/DietrichGebert/ponytail/tree/96608e078b2d5ea607c5c3b8b5a54d1c1fba6846)
at commit `96608e078b2d5ea607c5c3b8b5a54d1c1fba6846`. The gain skill’s evidence citation uses immutable upstream
URLs instead of unbundled local benchmark files. See [LICENSE](LICENSE).

This import contains instructions only. It preserves the six skill workflows
and adapts the help card to their unnamespaced shared-skill invocation. The
main skill's argument hint is preserved under the supported `metadata` field.
Each skill links to this source note and the shared license. The
upstream plugin's lifecycle hooks, persistent mode tracking, Claude Code band,
configuration reader, and plugin updater are not included. The shared
repository's installer and updater manage these skill files.
