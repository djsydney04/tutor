## Shared skills

At task start, read `.agents/SKILLS.md` and `.agents/guidance/skill-routing.md`.
Select the skills relevant to the task from `.agents/skills/`, then read and
follow their `SKILL.md` instructions and relevant references before acting.
Choose skills automatically; the user does not need to name them. Pass the
local guide and relevant skill paths to delegates for their own assignments.
Preserve this project's instructions and the user's task scope.

The files under `.agents/` are a one-time snapshot. Edit them for this project
as needed; they are not synchronized with the source collection. Keep edits in
this repository unless the user requests publishing them back.
